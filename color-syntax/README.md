# `.SYNC` Color Syntax

Hi there !

I have made two small package for color syntax for `.sync` programming language. It is avaible for **VS Code** and **VIM** editors.

I hope you enjoy it, if not you can still improve it 🤓

## Installation

Go see installation guides :

- [VS Code](./vscode/README.md)
- [VIM](./vim/README.md)
