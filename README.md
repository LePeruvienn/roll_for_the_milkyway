# roll_for_the_milkyway  

**par [Dimitri Watel](http://dimitri.watel.free.fr/)**


## Prérequis
- Python 3  
- pip3  
- PHP  
- Un navigateur web acceptant l’exécution de JavaScript  

## Installation
1. Extraire tous les fichiers de l’archive  
    (exemple : `local_roll_for_the_milkyway`)

2. Se placer dans le dossier du projet :

    ```bash
       cd local_roll_for_the_milkyway
    ````

3. Installer les dépendances :

   ```bash
   pip3 install -r requirements.txt
   ```

## Utilisation sous Linux

### Aide

```bash
python3 local_roll_for_the_milkyway.py -h
```

### Test rapide

```bash
python3 local_roll_for_the_milkyway.py chemin_vers_ia1.sync chemin_vers_ia2.sync ...
cd html
php -S localhost:8888 &
```

Ouvrir `index.php` dans un navigateur.
